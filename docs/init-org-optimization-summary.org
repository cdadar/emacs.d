* 已完成

** use-package 结构收敛
- 将多个分散的 ~(use-package org ...)~ 收敛为单一主块。
- 清理了散落的 ~(with-eval-after-load 'org ...)~，避免 Org 主配置分裂。
- 目前 Org 主配置的职责更清晰：
  - ~:custom~ 放基础变量
  - ~:hook~ 放简单 hook
  - ~:bind~ 放按键绑定
  - ~:config~ 放函数定义与集中初始化调用

** 解决配置互相覆盖问题
- 合并了 ~org-agenda-custom-commands~ 的定义，避免不同位置重复 ~setq~ 造成覆盖。
- 合并了 ~org-capture-templates~ 的定义，避免增量修改后又被整体重写。
- 将 Brain capture 模板并入统一 capture 配置，避免模板丢失。

** 清理未接线/历史遗留代码
- 删除了未真正启用的 dynamic agenda 相关 dead code。
- 去掉了旧式 advice/持久化思路带来的维护负担。

** Hook 与 keymap 整理
- 将反复在 hook 中修改 ~org-mode-map~ 的逻辑移出，避免每次进 buffer 重复做全局 keymap 修改。
- 将截图命令抽成独立函数，并绑定到 ~C-c s c~。
- 修正了 prose 相关逻辑里对 Org major mode 的判断。
- 保留了对 prose 体验的整理，但默认不自动启用 ~prose-mode~。

** Org 显示与导出修复
- 在 ~org-mode~ 中启用窗口内软换行，长 heading 与长行内容会在窗口内自动换行显示。
- 为视觉换行增加了 fringe 标记：~visual-line-fringe-indicators~ 设为 ~(left-curly-arrow right-curly-arrow)~，方便区分软换行与真实换行。
- 将 ~org-export-headline-levels~ 提升到 ~5~，让五级 Org heading 在 LaTeX 导出时继续保持为真实标题（直到 ~subparagraph~），而不是降级成 ~enumerate~ / ~\item~。
- 为 quote 导出增加了 ~cdadar/org-latex-fix-quote-paragraph-spacing~，仅在 LaTeX 导出时处理 ~quote~ 环境里的 ~\\ + 空行~，改写为显式竖向间距，避免 PDF 中空行后的内容向右偏移。

** Clock 显示体验
- 恢复了 clocking 时的 header-line 提示：clock in 时显示当前任务，clock out / cancel 时自动清理。

* 本轮：导出问题专项（2026-09-17）

** 历史笔记重新能出 PDF
- 新增导出 filter ~cdadar/org-latex-drop-duplicate-documentclass~：52 篇笔记在
  ~#+LATEX_HEADER~ 里自带 ~\documentclass[14pt]{article}~，Org 又输出一次默认 class
  声明，LaTeX 报 “Two \documentclass…” 后整篇产不出 PDF。filter 保留 Org 的声明，
  删掉同一 class 的重复声明；~\begin{document}~ 之后（正文里的 LaTeX 示例）不动，
  不同 class 的重复声明也不动。class 选项应写 ~#+LATEX_CLASS_OPTIONS~。
- 验证：~20241120194527-耶稣的救恩_召罪人.org~ 由「产不出 PDF」变为正常出 PDF。

** quote 负 vspace 兜底
- ~cdadar/org-latex-fix-quote-paragraph-spacing~ 现在还会删掉前言里旧笔记自改 quote
  环境时留下的 ~\endlist\vspace{-\baselineskip}~（文字重叠的元凶）。
- 验证：~20260815212757-与世界分别.org~、~20260829210526-认识肉体_十架.org~
  导出正常，生成的 =.tex= 中已无负 vspace。

** allowframebreaks 只留一套机制

** 缺字：按导出文本实际出现的字符注入回退字体
- XeTeX 不像 LuaTeX 那样自动字体回退，主字体（TeX Gyre Termes）没有带音/多音希腊文、
  圈号、制表符、几何符号（xeCJK 默认不管这些），导出后就是空白。
- 新增 filter ~cdadar/org-latex-add-glyph-fallback~：扫描导出后的 LaTeX 文本，只对里面
  真出现的字符按区间写 ~\newunicodechar~：希腊文（U+0370-03FF、U+1F00-1FFF）→
  SBL Greek；圈号/制表符（U+2460-24FF、U+2500-257F）→ CJK 字体（~cdadar/org-latex-cjk-main-font~）；
  几何符号（U+25A0-25FF）→ Apple Symbols。希腊文不带音的字也一并映射，避免同一个词
  里两种字体混排。无 fontspec 或已注入过的文档不动。
- 验证：~认识肉体_十架~（─ U+2500）、~教會生活~（ἐκκλησία）导出后日志 
  =Missing character= 为 0；渲染出的 PDF 里 ─ 是正常居中横线，ἐκκλησία 完整可读。
- 上轮当死代码删掉的旧符号回退（写死了 ①②③→Apple Symbols）没恢复：实测那套映射反而会把
  本来能渲染的 ①②③ 弄丢。

** 圈号统一为 ~\textcircled{N}~（手动命令，不做导出拦截）
- 新增 ~cdadar/org-replace-circled-numbers~（=M-x= 调用）：把 buffer 里的 ①..⑳ 换成
  ~\textcircled{N}~（笔记里早就用了 95 处这个写法，统一成同一个）。
- 跳过 =#= 开头的行（关键字/注释/块分隔符）与 ~src~ / ~example~ 块；整体算一次 undo，
  返回替换条数；重复调用幂等。
- 尝试过写成导出 filter，撤掉了：那篇笔记自己的 header 里有
  ~\newunicodechar{①}{{\symbolfallback ①}}~，导出拦截会把 header 里的 ① 也换成命令，
  把 ~\newunicodechar~ 砸出 =Invalid argument=。改成手动改源文件。
- 验证（副本上跑）：~摩西五经概论~ 改 4 处、~学道_诗篇73_76篇~ 改 17 处，
  注释行/关键字行/~src~ 块都没动。

** newunicodechar 重复定义同一字符会死循环
- 现象：~摩西五经概论~ 导出报 =! TeX capacity exceeded, input stack size=10000=，
  卡在 ~\item ▸~。
- 原因：~\newunicodechar~ 把字符设成 active；如果该字符已经 active（笔记 header 已映射），
  再定义一次时，**替换文本里那个字符会被当成 active token 再展开**，于是无限递归。
- 修法：~cdadar/org-latex-glyph-fallback-chars~ 遇到文本里已有
  ~\newunicodechar{<该字符>}~ 的字符就跳过（~cdadar/org-latex-unicodechar-mapped-p~）。
- 验证：该笔记重新导出，0 错误 0 递归，PDF 正常。

* 暂不建议动

** 不建议一次性全量改名旧 ~sanityinc/~ 标识
原因：
- 已有名字分布较广
- 可能影响用户习惯、历史配置和 muscle memory
- 本轮已经明确约束为“只改新整理出来的部分”

如果要做，应单独作为“命名空间迁移”任务处理。

** 不建议把所有逻辑都强行塞进 ~:custom~ / ~:hook~
有些逻辑天然更适合保留在函数和 ~:config~ 里，例如：
- advice
- 复杂 capture 模板生成
- Babel 图表工具发现
- Agenda 跳过逻辑
- 自定义命令定义

过度声明式化会让结构更隐晦，不一定更好维护。

** 不建议恢复运行时自动安装 diagram 依赖
已经移除的做法不建议再加回来：
- 启动时联网下载 jar
- 配置加载时执行 unzip / shell 安装流程
- 用不安全的远程源自动取文件

更稳妥的方式应是：
- 明确安装
- 明确路径
- 明确环境变量

** 不建议短期继续大规模重排整个文件顺序
当前已经完成了几轮结构重构并通过验证。
继续大幅重排会增加：
- diff 噪音
- 回归排查成本
- 未来 blame 难度

如果后续还要重排，建议基于明确目标单独进行，例如：
- “只整理 capture 区块”
- “只整理 roam 区块”
- “只整理 export/babel 区块”
